# Data statement

## Source corpus

- **Collection:** `CZLi/apt-reports` on Hugging Face (dataset revision
  `c06c0183be808d2e7b2bcbdb351426b75c8cde0f`; index file SHA-256
  `3275d2c19071d800bf3e0147105e66114b2aa94025576cd43e187edcff78ce12`),
  collected with CTI-Crawler (peng-gao-lab, MIT licence) in APT mode.
- **Licence of the collection:** tagged research-use-only. The collection README
  states that the reports remain the copyright of their original publishers and
  that copies are redistributed for non-commercial academic and security
  research; its own index files are CC BY 4.0.
- **Frozen study sample:** 72 reports (8 per publisher) from nine publisher
  categories: asec_apt, bitdefender_apt, groupib_apt, securelist_apt,
  sentinellabs_apt, talos_apt, trendmicro_apt, unit42_apt, volexity_apt.
  `dataset/reports.json` SHA-256 `461682f3…dd354e`; 144 prepared windows,
  `inputs.jsonl` SHA-256 `e22310e3…338500b`.

## What this repository contains

| Item | Contains report text? |
|---|---|
| `data/prepared/inputs_redacted.jsonl` (window, report, sentence IDs and SHA-256) | No |
| `data/prepared/manifest.json`, `data/config/study.json` | No |
| `checkpoints/*.zip` (model outputs as index lists, likelihood scores, hashes, logs) | No |
| `results/`, `docs/`, `protocol/`, `annotation/subset_*.csv` | No |
| `src/` code and test fixtures | No |

All files were scanned for verbatim matches against the 1,152 window sentences
before release; the only file that contained them (`inputs.jsonl`) was replaced
by its redacted form.

## What is withheld and how to obtain it

- **Window texts (`inputs.jsonl`):** rebuild from the public collection with
  `src/v216_inference` (corpus acquisition and preparation are deterministic and
  hash-checked), or request the exact file from the author for non-commercial
  research. `reproduce/restore_reference_archive.py` verifies either source.
- **Report URL index:** `data/report_sources.csv` (report ID → publisher URL,
  archive path, HTML hash) when generated by the author with
  `tools/export_report_sources.py`.
- **Model weights:** download the pinned revisions from Hugging Face:
  Qwen/Qwen2.5-3B-Instruct `aa8e7253…`, meta-llama/Llama-3.2-3B-Instruct
  `0cb88a4f…`, mistralai/Mistral-7B-Instruct-v0.3 `c170c708…` (full hashes in
  `data/config/study.json`). Their licences apply to model outputs.

## Human annotation

`annotation/` defines a 36-window (288-sentence) subset that was selected before
labelling, with a fixed salt and without reading model outputs. Released label
files contain item identifiers and 0/1 labels only.

## Personal data

None. The reports are public vendor threat-intelligence publications; no
personal data were collected for this study.
